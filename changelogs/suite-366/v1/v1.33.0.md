# Version 1.32.0 → 1.33.0

---

## ✨ Nouvelles fonctionnalités & améliorations

- **Réunions et salons vocaux : flou et fond virtuel de la caméra** :
  - effets disponibles : flou léger, flou fort, 8 fonds prédéfinis ou une image importée, qui reste dans le navigateur ;
  - réglable depuis le lobby, les réglages de la salle et les réglages vocaux du chat, sans couper la caméra ;
  - le traitement se fait dans le navigateur : les autres participants et l'enregistrement ne reçoivent que l'image traitée ;
  - une option « Haute qualité » offre un détourage plus précis ; si elle ne peut pas se charger, l'effet standard prend le relais.

- **Réunions : détection de deepfake** :
  - le nombre d'analyses par participant est désormais limité (24 analyses d'image et 12 analyses audio par défaut, configurable), après quoi le verdict est figé ;
  - les participants qui rejoignent une réunion en cours voient les verdicts déjà établis ;
  - les partages d'écran et les silences ne sont plus analysés.

- **Agents et PersonIA** :
  - une réponse coupée par la limite de longueur du modèle est relancée automatiquement ; si elle reste incomplète, la PersonIA le signale dans le chat et le tour apparaît en échec au lieu d'un succès silencieux ;
  - un agent peut compléter un fichier existant sans le réécrire ;
  - un sous-agent dispose de 20 minutes au lieu de 5, ce qui évite les interruptions avec les modèles locaux ;
  - les activités PersonIA et le chat d'agent affichent la durée réelle de chaque outil.

- **Agents et navigation web** : sur les PersonIA existantes, interagir avec une page et y téléverser un fichier demandent désormais une validation.

---

## 🛠️ Corrections de bugs / sécurité

- **Fix — Agents et PersonIA** :
  - avec un fournisseur de modèle personnalisé, le résumé des longues conversations tient compte de la taille de contexte déclarée pour le modèle ; il se déclenchait auparavant bien trop tôt ;
  - dans l'historique d'une PersonIA, chaque réponse rappelle le message auquel elle répond.

- **Fix — Chat** :
  - l'aperçu des conversations n'affiche plus de mise en forme brute ni de code d'emoji ; les GIF et les photos y apparaissent avec une icône et un libellé ;
  - les mentions s'affichent sous la forme `@Nom` dans la citation d'un message et dans le bandeau « Répondre à » ;
  - le menu des mentions passe au-dessus du message survolé ;
  - le bouton « Arrêter » d'une PersonIA reprend le style de la zone de saisie.

- **Sécurité** : correction d'un défaut de contrôle d'accès sur les Pages.
