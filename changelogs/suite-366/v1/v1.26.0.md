# Version 1.25.2 → 1.26.0

## ✨ Nouvelles fonctionnalités & améliorations

- **Agents** : premières bases du navigateur des agents (phase 1).

- **Pages** : zoom plein écran sur les diagrammes Mermaid.

- **Chat** : un bloc de texte copié garde sa mise en forme.

- **Traitements** : les dernières exécutions et les métriques mènent directement à la file concernée.
