# Version 1.34.1 → 1.35.0

---

## ✨ Nouvelles fonctionnalités & améliorations

- **Tableau blanc dans les réunions et les salons vocaux** :
  - un bouton à côté du partage d'écran ouvre un tableau blanc collaboratif dans une fenêtre flottante ; chacun voit les dessins et les curseurs des autres en temps réel, invités d'une réunion publique compris ;
  - le tableau est conservé pendant la réunion et effacé à sa clôture ; dans un salon vocal, la fenêtre reste ouverte quand on change de page ;
  - quand quelqu'un dessine, les autres participants en sont avertis et peuvent ouvrir le tableau d'un clic ;
  - tout est hébergé par l'instance, sans service extérieur.

- **Nouveaux blocs dans le chat et les Pages** : les agents et les utilisateurs peuvent insérer neuf nouveaux types de blocs, rendus à l'identique dans une conversation et dans une page :
  - fiche d'un élément CRM, liste de tâches cochable, workflow avec son statut et un bouton pour le lancer ;
  - une page ou une de ses sections, toujours à jour ; une réunion et ses notes ; un enregistrement avec sa transcription cliquable ;
  - le voisinage d'une entité du graphe de connaissances ; un agenda ou des créneaux à choisir ;
  - un brouillon de mail ou d'événement proposé par un agent, qui ne part qu'après validation de l'utilisateur, depuis son propre compte, destinataires affichés ;
  - chaque bloc respecte les droits de la personne qui le consulte : un contenu auquel elle n'a pas accès reste masqué ;
  - dans les Pages, ces blocs s'insèrent depuis le menu `/`.

- **Drive** : « Déplacer vers » propose désormais Déplacer (par défaut) ou Copier. Vers le dossier d'une équipe, un élément qui nous appartient est réellement déplacé et prend les droits de l'équipe ; dans les autres cas, le choix entre partager et copier est proposé comme avant.

- **Tâches** :
  - un interrupteur dans l'en-tête du panneau choisit si les nouvelles tâches que l'on se crée sont privées ou publiques ;
  - nouveau widget de tableau de bord « Mes todos » : tâches ouvertes classées par échéance, retards en tête, à cocher ou à ouvrir d'un clic.

- **Carte d'un membre dans le chat** :
  - les tâches en retard y apparaissent en tête, avec des pastilles d'échéance ;
  - un bouton ouvre directement la conversation avec la personne, et une image collée dans la carte l'attend dans la zone de saisie ;
  - pendant une réunion, la conversation s'ouvre dans une fenêtre flottante sans quitter l'appel.

- **Agents et PersonIA** :
  - les agents peuvent déplacer une page, sous une autre page, à la racine ou vers un autre espace, avec ou sans ses sous-pages ;
  - un appel d'outil incomplet est refusé avant son exécution, avec le nom du paramètre manquant : l'agent corrige son appel au lieu d'échouer sur une erreur générique.

## 🛠️ Corrections de bugs / sécurité

- **Fix — Chat sur mobile et tablette** :
  - les blocs d'une conversation (schémas, documents, code) s'ouvrent sur téléphone et tablette ;
  - les grands schémas restent lisibles et défilent, les tableaux défilent au lieu de couper les mots ;
  - le panneau d'un fil de discussion ne dépasse plus de l'écran ;
  - une réponse qui commence directement par un bloc l'affiche correctement, sur ordinateur comme sur mobile.

- **Fix — Défilement** : la recherche de messages et la liste des messages épinglés défilent au-delà de quelques résultats, et les barres de défilement de l'application suivent à nouveau la position réelle.

- **Fix — Participants du chat** : une PersonIA supprimée ou un membre désactivé n'apparaît plus dans la liste des participants, le compteur ni les mentions ; ses anciens messages restent signés.

- **Fix — Application de bureau** : l'installeur affiche de nouveau l'icône de Suite 366.
