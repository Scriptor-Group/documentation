# Version 2.0.31 → 2.0.32

---

## ✨ Nouvelles fonctionnalités & améliorations

- **Configuration — réutilisation des extractions** : une nouvelle option de déploiement permet de désactiver la réutilisation du résultat d'extraction quand un fichier au contenu identique a déjà été traité ; chaque import est alors traité à nouveau. Sans cette option, le comportement est inchangé. Voir les [variables d'environnement d'Odin](../../../deployment/configuration/environment-variables.md#odin-service-de-traitement).
