## Version 2.0.22

### 🐛 Corrections de bugs

- 📧 **Contournement du cache pour les fichiers mail** : détection par extension (`.eml` / `.msg`) en repli du mimetype, celui-ci pouvant être absent de `MIME_MAP` (cas de `application/vnd.ms-outlook`).
- 🔗 **Contournement du cache quand `from_task_id` est présent** : une tâche dérivée n'est plus servie depuis le cache.
- 📎 **Pièces jointes des fichiers mail** : plus de création d'attachments dans les chunks pour ces fichiers.
