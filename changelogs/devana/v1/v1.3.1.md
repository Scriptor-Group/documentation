# Version 1.3.0 → 1.3.1

---

## ✨ Nouvelles fonctionnalités & améliorations

- **Cache de prompt OpenAI** : les échanges avec les modèles OpenAI tirent désormais parti du cache de prompt du fournisseur.
  - Réduction du coût des tokens d'entrée sur les appels successifs d'un même agent (jusqu'à ~90 % sur la partie stable du prompt) et latence améliorée.
  - Les tokens servis depuis le cache sont comptabilisés dans les statistiques d'appels de chaque conversation.
  - Les agents reçoivent maintenant la date du jour sans l'heure dans leurs instructions.

---

## 🛠️ Corrections de bugs / sécurité

- **Fix — Terminal de debug** : sur une session longue, le terminal pouvait saturer le stockage du navigateur et faire planter l'interface. L'historique conservé est désormais plafonné.

- **Fix — Modèles Bedrock** : lorsqu'un agent cumule plusieurs blocs d'instructions système, tous sont pris en compte au lieu du dernier seulement.

---

## 🔧 Maintenance

- Nettoyage de code inactif dans le traitement des agents — sans impact fonctionnel.
