# Version 1.3.5 → 1.3.6

---

## ✨ Nouvelles fonctionnalités & améliorations

- **Agents — retrait de l'outil « Code Executor »** : l'outil d'exécution de code n'est plus proposé dans la configuration des agents et il est désactivé sur les agents existants, y compris ceux qui l'avaient reçu par défaut. Les autres outils natifs ne changent pas.

- **API — langue par défaut des réponses** : lorsque le paramètre `lang` n'est pas fourni, la langue n'est plus déduite de celle du compte qui porte la clé API ; la réponse suit la langue de la question. `lang` reste disponible pour imposer une langue.

---

## 🛠️ Corrections de bugs / sécurité

- **Fix — Langue des réponses** : une question posée dans une autre langue que celle du compte (en anglais depuis un compte configuré en français, par exemple) pouvait recevoir une réponse en français, surtout lorsque la réponse s'appuyait sur de nombreux documents. La réponse suit désormais la langue de la question.

- **Fix — Bases de connaissances** : les fichiers importés par un connecteur (Magnolia, SharePoint…) ou rangés dans un ancien dossier n'apparaissaient ni dans la liste des fichiers de la base ni dans la recherche par nom, alors qu'ils étaient bien indexés et utilisés dans les réponses. Ils sont de nouveau listés.
