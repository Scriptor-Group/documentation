# Version 1.3.4 → 1.3.5

---

## ✨ Nouvelles fonctionnalités & améliorations

- Aucune nouvelle fonctionnalité majeure sur ce cycle — release principalement axée corrections et maintenance.

---

## 🛠️ Corrections de bugs / sécurité

- **Fix — Authentification** : le renouvellement automatique de session introduit en 1.3.3 se déclenchait plus tard que prévu, avec une marge réduite de moitié ; dans un onglet resté en arrière-plan, la session pouvait expirer avant d'être renouvelée. La marge prévue est rétablie.

- **Fix — Connecteurs CMS** : sur une instance sans résolution DNS externe dont le trafic sortant passe par un proxy, l'ajout d'un CMS (Magnolia) ou d'un site web était refusé. La connexion aboutit désormais via le proxy ; les autres contrôles sur les adresses cibles restent inchangés.
