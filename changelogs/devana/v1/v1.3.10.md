# Version 1.3.9 → 1.3.10

---

## ✨ Nouvelles fonctionnalités & améliorations

- **Bases de connaissances isolées** : une base de connaissances peut désormais appartenir à un groupe et rester isolée, sans être mélangée à celles des agents ni aux autres sujets.
  - Les groupes déclarent des champs d'identification (par exemple référence, modèle, année) que chaque base renseigne ; une clé unique permet de créer ou de mettre à jour une base sans doublon.
  - Nouvel onglet « KB isolées » dans la gestion des connaissances, action « Rendre isolée » sur la page d'une base, et rattachement de groupes dans l'éditeur d'agent.
  - Dans le chat, un sélecteur de sujet permet de choisir la base consultée ; le sujet actif reste visible dans la conversation.
  - Un agent peut retrouver lui-même le sujet d'une conversation, et demande à l'utilisateur de préciser lorsque plusieurs bases correspondent. Cette option, à activer dans l'éditeur d'agent, est désactivée par défaut.

- **Serveurs MCP : transmission de l'identité de l'utilisateur** :
  - Nouvelle option par serveur, désactivée par défaut, qui permet à un serveur MCP de savoir pour quel utilisateur Devana l'appelle, afin d'adapter ses réponses aux droits de cette personne.
  - Compatibilité avec les serveurs MCP utilisant le protocole actuel.

## 🛠️ Corrections de bugs / sécurité

- **Fix — Connecteur CMS** : après la modification du modèle d'URL des FAQ, les liens des sources pouvaient pointer vers la page d'accueil, sans la page ni l'ancre attendues. Ils sont désormais recalculés correctement, sans attendre la synchronisation suivante.

- **Sécurité** : durcissement du contrôle d'accès aux agents.
