# Version 1.2.13 → 1.3.0

---

## ✨ Nouvelles fonctionnalités & améliorations

- **Modèles de réflexion (reasoning)** :
  - Compatibilité avec les modèles de réflexion OpenAI — ajout de GPT-5.4 et GPT-5.4-mini.
  - Niveau de réflexion réglable par rôle de LLM dans la configuration des agents.

- **Support du proxy LiteLLM** : les modèles peuvent désormais être servis via un proxy LiteLLM.

- **Bases de connaissances** :
  - Barre de progression d'import de documents par base de connaissance.
  - Affichage de la cause d'échec d'extraction d'un fichier, avec possibilité de relancer l'extraction.

- **Endpoint `/api/health`** sur le front pour les probes Kubernetes (liveness / readiness).

- **Interface** :
  - Nouvelle police Geist en remplacement de Usual.
  - Ajout de 120 clés de traduction manquantes (fr / en).
  - Graphe des messages dans les métriques : passage en nombre par jour avec moyenne.

---

## 🛠️ Corrections de bugs / sécurité

- **Fix — Ingestion documentaire** : un fichier ne peut plus rester bloqué indéfiniment à l'état « Extraction ».

- **Fix — Anthropic** : correction des réponses vides et des arguments d'outils qui n'étaient jamais corrigés automatiquement.

- **Fix — Outils personnalisés** : les outils personnalisés effectuant des modifications demandent désormais une confirmation par défaut.

- **Fix — Agents créés par API** : un agent créé via l'API n'est plus publié automatiquement sans que ce soit demandé.

- **Fix — Jobs** : l'arrêt d'un job ne cible plus l'ensemble des jobs de l'instance.

- **Fix — Historique des conversations** : correction d'un crash au chargement de la suite de l'historique, et debounce effectif sur la recherche.

- **Fix — Métriques** : le graphe des messages ne s'affiche plus vide.

- **Fix — Sélection de modèle** : correction de la sélection du modèle pour le tooling, et amélioration des logs LLM.

- **Fix — Logs** : suppression d'un faux avertissement Chroma sur les collections pré-existantes.

- **Sécurité** : remédiation de 13 CVE runtime signalées par Dependabot (front + serveur).

- Mise à jour du SDK OpenAI en v7.
