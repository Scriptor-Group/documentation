# Version 1.3.2 → 1.3.3

---

## ✨ Nouvelles fonctionnalités & améliorations

- **Portabilité des agents** :
  - L'export d'un agent est désormais déterministe : deux exports du même agent produisent un fichier identique, ce qui permet de comparer un agent avant/après modification, ou deux agents jumeaux sur deux instances.
  - L'URL de webhook n'est plus emportée dans l'export : elle reste vide sur un agent créé par import, et inchangée sur un agent existant mis à jour par import.
  - Le mode Agentic (Beta) et la sélection d'outils natifs (dont « Code Executor ») sont maintenant repris à l'export comme à l'import.
  - Un fichier d'import comportant une valeur invalide pour les outils natifs est refusé dès la prévisualisation, et non plus seulement à l'application.

---

## 🛠️ Corrections de bugs / sécurité

- **Fix — Authentification** : la session tombait au bout d'une heure et renvoyait à l'écran de connexion, sans renouvellement automatique.
  - La session est désormais renouvelée avant son expiration, ainsi qu'au retour sur un onglet resté ouvert.
  - Le rechargement d'une page protégée après expiration tente d'abord un renouvellement, et ne renvoie à la connexion qu'en cas d'échec.

- **Fix — Agents** : dupliquer un agent perdait plusieurs réglages de l'écran Outils (prompt d'identité, identité webhook, mode Agentic, outils natifs). Ils sont désormais repris sur la copie.

- **Fix — Modale Outils** : rechercher un outil vidait le sélecteur d'outil parent et affichait « Aucun outil parent » sous les outils dont le parent était hors des résultats. Le sélecteur reste peuplé quelle que soit la recherche, et accepte désormais la saisie.

- **Fix — Traductions** : dans la modale Outils, « outils connectés » était traduit « appareils connectés » en français, allemand, espagnol, portugais et chinois.

- **Sécurité** : renforcement des contrôles d'accès sur le flux d'authentification.
